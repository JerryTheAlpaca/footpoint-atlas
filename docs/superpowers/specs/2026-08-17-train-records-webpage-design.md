# 火车乘车记录展示网页 —— 设计文档

日期：2026-08-17
状态：已获用户批准

## 1. 目标

把个人的火车乘车记录做成一个本地静态网页：深色科技风、带丰富动画，展示坐过的线路、到访的车站、坐过的车型及其次数。双击 `index.html` 即可打开，完全离线可用。

## 2. 数据源

唯一数据源为 `js/data.js`（不用 Excel / CSV / 后端）。原始 Excel（`火车乘车记录.xlsx`）仅作存档，网页不读取。

选择理由：网页零解析零转换；浏览器 file:// 协议下无法 fetch 本地 `.json`/`.csv`，故用 `.js` 赋值形式（`window.TRAIN_DATA = {...}`）；Git diff 友好；27 条记录体量适合手写维护。

### data.js 结构

```js
window.TRAIN_DATA = {
  records: [
    {
      date: "2023-08-04",   // 统一 ISO 格式
      from: "郑州东",
      to: "武汉",
      train: "G65",
      vehicle: "CR400AF-Z-0212",  // 原始车号，重联保留 "+" 连接与说明
      origin: "北京西",            // 该车次始发站
      terminal: "武汉",            // 该车次终到站
      bureau: "武汉局"
    }
    // ... 共 27 条
  ],
  stations: {
    "南京南": [118.81, 31.97],   // 经纬度，与 china.json 同一坐标系（GCJ-02）
    // ... 共 20 个
  }
};
```

### 统计口径（app.js 加载时自动计算，不预存）

- 总乘坐次数 = records 长度（27）
- 线路 = 有向 pair（发站 → 到站），共 23 条；汉口→南京南、南京南→汉口 各 3 次为最频繁
- 车站次数 = 作为发站或到站出现的次数，共 20 个站；南京南 14 次居首
- 车型 = 从车号提取型号前缀（如 `CR400BF-Z-3131` → `CR400BF-Z`）；重联车号按 `+` 拆分后每个型号各计 1 次；共 16 种
- 路局分布 = 按 records 的 bureau 计数（上海局 10、广州局 6、武汉局 4、成都局 3、北京局 2、西安局 1、郑州局 1）
- 轨迹总里程 = 站间直线距离（haversine）求和，界面标注「按直线估算」

## 3. 项目结构

```
火车乘车记录/
├── index.html            # 主页面
├── css/style.css         # 深色科技风样式
├── js/data.js            # 唯一数据源
├── js/app.js             # ECharts 初始化、动画、时间轴回放、统计计算
├── lib/echarts.min.js    # ECharts 5（本地下载，离线可用）
├── map/china.json        # 中国 GeoJSON（本地下载，GCJ-02 坐标系，离线可用）
├── docs/                 # 设计文档
└── 火车乘车记录.xlsx      # 原始数据存档
```

## 4. 技术选型

- ECharts 5（本地 lib）：geo 地图 + lines 流光特效 + effectScatter 涟漪 + bar/pie 排行榜 + timeline 回放组件。动画水准高、开发快。
- 中国 GeoJSON 与车站坐标统一用 GCJ-02，避免偏移。
- 不使用 Leaflet/在线瓦片（离线不可用）；不使用 D3 手写（开发量大）。

## 5. 页面布局（深色科技风：深蓝黑底 + 霓虹光效）

1. **顶部**：标题「我的火车足迹」+ 4 个统计卡（总次数 / 到访车站 / 车型数 / 估算总里程），数字滚动增长动画
2. **主区（左约 2/3）**：中国地图
   - 深蓝黑底图，23 条线路带流光拖尾持续流动
   - 20 个车站涟漪光点，大小 ∝ 到访次数
   - 悬停线路/车站显示 tooltip：日期、车次、车型、路局、该线路乘坐次数
3. **地图下方**：时间轴回放条（播放/暂停/拖动），按日期 2023-08 → 2026-08 逐条点亮线路
4. **右侧约 1/3**：车型排行、车站排行（横向柱状图入场动画）、路局分布（玫瑰图）
5. **底部**：乘车记录时间线列表（按日期），悬停某条时地图对应线路高亮

## 6. 动画清单

1. 加载：统计数字滚动、图表依次入场
2. 常驻：线路流光、车站涟漪
3. 时间轴回放：逐条点亮 + 可拖动进度
4. 交互：悬停高亮 + tooltip

## 7. 错误处理

- `china.json` 或 `echarts.min.js` 缺失/加载失败：页面显示明确中文错误提示而非白屏
- data.js 中车站缺坐标：控制台警告并跳过该点，不中断渲染

## 8. 验证方式

- 用浏览器打开 `index.html`，截图核对：统计数字与 Excel 一致（27 / 20 / 16 / 23）
- 目检地图动画、时间轴回放、排行榜、悬停联动
- 控制台无报错

## 9. 不做的事（YAGNI）

- 不做后端服务、不做在线编辑界面、不做移动端深度适配（仅保证缩放基本可用）、不做真实铁路走向（站间用直线/弧线近似）
